# Roadmap

## 0.1 — local prototype
- Ten analytical scalar benchmarks; explicit tolerances; JSON CLI and Python API.
- Three-grid observed order and Richardson extrapolation with restrictive input checks.
- Unit and CLI tests; docs; CI configuration.

## 0.2 — public MVP
- Verify package name availability and run hosted CI.
- Independently review equations, assumptions and source citations.
- Add JSON Schema, CSV adapter, unit conversion and error reporting.
- Reproduce at least one open-source CFD and one structural benchmark end to end.

## 0.3 — ecosystem
- Document reusable OpenFOAM and CalculiX result extraction workflows.
- Add versioned benchmark data, provenance and a contribution review checklist.
- Add CI examples for downstream users and publish a package after review.
- Seek actual users and maintainers; prioritize feedback over contribution counts.

Non-goals: running proprietary solvers, guaranteeing simulation correctness, claiming validation/certification, or fabricating community metrics.
