# Reproducible finite-volume pipe-flow check

Run from an installed checkout:

    python examples/radial_fvm.py

The independent demonstration solves a steady, axisymmetric, fully developed Newtonian pipe flow problem on radial annular cells. It does not call the analytical formula to generate velocity or volumetric flow. The governing momentum equation is -d(r du/dr)/dr = r DeltaP/(mu L), with zero radial flux at the axis and no slip at the outer wall. Integrating over each annulus produces a tridiagonal system for the cell-centred velocities; the wall uses a half-cell distance. Flow is integrated as the sum of each annular area times its cell velocity.

The Veritas benchmark independently compares the computed flow rate to Hagen–Poiseuille flow and reports the relative error and observed grid order. Default inputs use radius 1 mm, length 1 m, viscosity 1 mPa s and pressure drop 1 kPa. With water-like density the expected Reynolds number is about 250, consistent with laminar flow. The script does not automatically check density or regime. Four radial grids (8, 16, 32, 64 cells) demonstrate the discretization error; this is not evidence of general CFD accuracy or of a production solver integration.

The result is generated by executing the example, not by supplying invented external solver output. No OpenFOAM or CalculiX claims are made.
