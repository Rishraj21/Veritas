# Phase 1 — Fluid mechanics: research bibliography and implementation evidence map

Review date: 2026-11-27. Scope: undergraduate introductory engineering fluid mechanics (FM01–FM15), not advanced turbulence or general-purpose CFD. This is a research and implementation specification, not a statement that all chapters or equations have been implemented or that the models are certified.

## Reading status and access

- **S (section inspected):** accessible substantive text/equations or a technical section excerpt was examined. This does not mean every chapter of the work was read.
- **T (contents inspected):** publisher contents, syllabus, chapter listing or catalog information was examined for coverage.
- **M (metadata only):** bibliographic record/abstract or index only; cannot establish equation validity or correlation limits.
- Access is public HTML unless otherwise indicated. Copyright remains with each owner; no proprietary tables, example text, illustrations or code are included. Record exact edition, section, access, licensing and validity envelope before using any correlation. Do not describe T/M sources as books read cover to cover.

## D. Browser-first implementation gates

1. Scalar calculators: O(1) auxiliary memory and synchronous JS; no WebAssembly/Worker startup for a handful of arithmetic operations. Use a canonical model per language and shared independent fixtures. Preserve explicit SI unit labels; dimension-compatible tagged inputs are a separate integration task, not silently assumed.
2. Profiles and plots: evaluate on demand, cap samples, typed arrays only when needed. Avoid representing functions as large stored tables.
3. Roots, trajectories and networks: use safeguarded existing methods, report failure and branch; worker for expensive work. Reuse factorizations, CSR or matrix-free operators when structure warrants them. Avoid mandatory scientific Python download in browser.
4. Correlations: document equation/source edition, units, geometry, regime/range and property state. Compare explicit approximations against implicit reference over a reproducible test grid; report maximum/RMS errors and measured cost. Do not assume a textbook TOC establishes correlation validity.
5. Verification: independent analytical values, limiting cases, sign/datum conventions, invalid inputs, conservation and cross-language agreement; for numerical models, refinement and residual checks. Add live browser smoke checks. No claim of physical validation merely from passing tests.
6. Source tracking: append new source records as a model is reviewed; do not mark a source fully read unless it actually was. For future sources such as IAPWS property releases, NIST fluid data, ISO 5167 differential-pressure metering, pump test standards and open boundary-layer references, verify exact edition/license and access before using. These are candidates, not inspected sources.

## E. Immediate research/implementation order

- Finish FM02 analytic statics and layer/manometer models, then FM03 kinematics and FM04/05 control volume and energy.
- FM06 dimensional analysis early, followed by FM07/08 internal flow; compare Colebrook approximations before selecting a default.
- FM09/10/11 measurement, external flow and machines; prioritize verified correlation domains rather than count of calculators.
- FM12/13 channels and gas dynamics; branch-aware roots and independent reference values.
- FM14/15 connect to the verified numerical engine and uncertainty layer; retain separate numerical and physical validity.
- Current FM01/initial FM02 code snapshot ed4bfc8 passed the full hosted CI run [45909978237](https://github.com/Rishraj21/Veritas/actions/runs/45909978237). The research ledger is not evidence that the remaining models have been tested.

## F. Known research gaps

No full commercial textbook has been read cover-to-cover in this review. The two Bar-Meir books have been identified/indexed, not fully read; the LibreTexts main page failed to load directly. Full primary Colebrook/Moody papers and quantitative validity comparisons remain outstanding. Specialist boundary-layer, property, pump and instrument correlations require equation-level sources. This ledger establishes all fifteen topic families and a transparent route to implementation, not final coverage of every subtopic or experimental validation.
